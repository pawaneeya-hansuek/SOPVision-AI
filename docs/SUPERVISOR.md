# หน้าหัวหน้างาน

เปิด `/login` แล้วกรอกบัญชีและรหัสผ่าน ระบบอ่านสิทธิ์จากบัญชีแล้วเปิดหน้าที่ตรงกันอัตโนมัติ แอดมินไป `/admin` หัวหน้างานไป `/supervisor` ไม่ต้องเลือกบทบาทก่อนเข้าสู่ระบบ ลิงก์เดิม `/supervisor/login` เปลี่ยนมาหน้าเข้าสู่ระบบเดียวกัน

แอดมินสร้างบัญชีได้ที่ `/access` เลือกบทบาทหัวหน้างานและตั้งชื่อบัญชีกับรหัสผ่านของแต่ละคนแยกจากแอดมิน รหัสผ่านเดิมของแอดมินยังคงเดิม ไม่มีบัญชีหรือรหัสผ่านเริ่มต้นเพิ่มให้

หัวหน้างานทำได้สองอย่าง:

1. เปิดงานรออนุญาต ระบุเหตุผลอย่างน้อย 10 ตัวอักษร แล้วกด **อนุญาตให้สแกนงานซ้ำ** พนักงานจึงสแกน QR เดิมเริ่มรอบใหม่ได้ ระบบเก็บผลเดิม ผู้อนุญาต เวลา เหตุผล และความเชื่อมโยงกับรอบใหม่ การอนุญาตไม่ทำให้งานผ่านหรือปลดล็อกสเตชั่นถัดไป
2. ค้นหาและดูวิดีโอย้อนหลัง ทั้งคลิปประจำชิ้นงานและคลังกล้อง พร้อมระบุคลิปที่รับไม่ครบ พิมพ์รหัสหรือยิงเครื่องสแกนในช่องค้นหาแล้วกด Enter ได้ หรือกด **สแกน QR ด้วยกล้อง** เพื่อใช้กล้องมือถือ เมื่ออ่านได้จะปิดกล้องและค้นหาอัตโนมัติ ใช้ HTTPS บนมือถือและอนุญาตกล้องก่อนสแกน

ระบบจำกัดสิทธิ์ทั้งหน้าจอและ API หัวหน้างานเข้ารายงานแอดมิน จัดการผู้ใช้ แก้ SOP เปลี่ยนผลตรวจ ปฏิเสธงาน ดูกล้องสด เริ่มงาน หรือสร้างรอบทดสอบด้วยบัญชีหัวหน้างานไม่ได้

หน้าพนักงานแสดงกล้องตามสัดส่วนจริงของภาพ มีปุ่ม **ขยายภาพ** และ **ย่อภาพ** กด Escape เพื่อย่อบนคอมพิวเตอร์ได้ ข้อความสถานะบันทึกอยู่ใต้ช่องสแกนเพื่อไม่บังปุ่ม
