# การใช้งานให้ต่อเนื่อง

- เปิด `start_windows.bat` สำหรับคอมพิวเตอร์ แล้วเข้า http://127.0.0.1:8000/worker หรือ http://127.0.0.1:8000/admin
- เปิด `start_mobile.bat` เพิ่มสำหรับมือถือ ใช้ HTTPS และ IP ที่โปรแกรมแสดง มือถือกับคอมต้องอยู่ Wi-Fi ที่เข้าถึงกัน และมือถือเชื่อถือใบรับรองตาม README
- ตัวเปิดติดตั้งส่วนประกอบเฉพาะเมื่อยังไม่มี หลังติดตั้งครบแล้วไม่ต้องดาวน์โหลดใหม่ทุกครั้ง
- ใช้เซิร์ฟเวอร์หลักตัวเดียว ห้ามใช้ `--reload` หรือหลาย workers ขณะทำงาน ทางเข้ามือถือส่งข้อมูลเข้าเซิร์ฟเวอร์เดียวกับคอม ระบบป้องกันเซิร์ฟเวอร์หลักตัวที่สองเปิดฐานข้อมูลเดียวกัน
- เปิดหน้ากล้องค้างไว้และอย่าล็อกมือถือ ถ้าสัญญาณขาดชั่วคราว ระบบส่งข้อมูลเดิมซ้ำได้โดยไม่เพิ่มคลิปซ้ำ หากส่งไม่สำเร็จภายในเวลาที่กำหนดจะแจ้งข้อผิดพลาดและเก็บสถานะคลิปไม่ครบ
- ระบบตรวจงานและกล้องที่ไม่ส่งข้อมูลเกิน 45 วินาทีเองทุกประมาณ 5 วินาที โดยไม่ต้องให้แอดมินเปิดหน้าจอ ภาพสดที่เก่าจะไม่แสดงเป็นออนไลน์
- ฐานข้อมูลใช้ WAL และบันทึกแบบ FULL เพื่อให้หน้าแอดมินอ่านข้อมูลได้ขณะมีการเขียนงานหรือคลิป การเขียนไฟล์วิดีโอไม่ขวางวงรอบรับส่งคำขอของเซิร์ฟเวอร์
- ก่อนอัปเดตหรือปิดเครื่อง ให้จบงาน ปิดกล้อง และรอข้อความยืนยันการบันทึก หากเครื่องดับระหว่างงาน ระบบจะพักงานและระบุคลิปที่ไม่ครบหลังเริ่มใหม่ โดยไม่เปลี่ยนให้เป็นงานผ่าน
- สำรองฐานข้อมูลด้วย SQLite backup API พร้อมโฟลเดอร์ `media` ขณะไม่มีงานและกล้องทำงาน การคัดลอกเฉพาะ `sopvision.db` ขณะเปิดใช้งานอาจไม่รวมข้อมูลในไฟล์ WAL

การปิดหน้าจอมือถือ ไฟดับ พื้นที่เต็ม และเครือข่ายล่มยังทำให้บันทึกขาดช่วงได้ ระบบแจ้งและรักษาสถานะข้อผิดพลาดแทนการยืนยันว่าบันทึกครบ ควรใช้ไฟสำรองและสำรองข้อมูลแยกเครื่องสำหรับงานจริง
