# แผนผังไฟล์ SOPVision AI

| ตำแหน่ง | ใช้สำหรับ |
|---|---|
| `start_windows.bat` | เปิดระบบบนคอมพิวเตอร์ |
| `start_mobile.bat` | เปิดทางเข้ามือถือ |
| `main.py` และโมดูล Python ที่รากโปรเจกต์ | โค้ดระบบ ตำแหน่งเดิมเพื่อให้ตัวเปิดระบบและการเชื่อมต่อทำงานต่อได้ |
| `static/` | หน้าเว็บ รูปแบบหน้าจอ และสคริปต์บนเบราว์เซอร์ |
| `tests/` | ชุดทดสอบระบบและหน้าจอ |
| `docs/` | คู่มือหัวหน้างาน ความเสถียร และบันทึกการแก้ไข |
| `output/` | QR, PDF และไฟล์ที่ส่งให้ผู้ใช้งาน |
| `output/previews/` | ภาพตัวอย่างหน้าจอ |
| `artifacts/test-runs/` | ไฟล์จากการทดสอบใหม่ |
| `artifacts/test-runs/archived/` | ผลทดสอบเก่าที่ย้ายมาจากหน้าหลัก |
| `artifacts/cache/pytest/` | แคชของชุดทดสอบ |
| `artifacts/organization-*.json` | บันทึกต้นทางและปลายทางของไฟล์ที่จัดหมวด |
| `backups/` | สำรองข้อมูลก่อนอัปเดต |
| `backups/legacy/` | สำรองข้อมูลรุ่นก่อนที่เคยอยู่หน้าหลัก |
| `media/` | วิดีโอและภาพหลักฐานจริง รวมถึงสำเนาสำหรับเล่นย้อนหลัง |
| `sopvision.db` | ฐานข้อมูลจริง |
| `tools/organize_workspace.ps1` | ดูแผนจัดหมวด และใช้ `-Apply` เพื่อย้ายไฟล์ที่เข้าเงื่อนไข |

## การแสดงผลใน VS Code

ไฟล์ประกอบถูกรวมเป็นกลุ่มใน Explorer ใต้ `main.py`, `README.md` และ `start_windows.bat` โดยไม่เปลี่ยนตำแหน่งจริงของโค้ด กดลูกศรข้างไฟล์เพื่อขยายได้

โฟลเดอร์แคช ไลบรารี สภาพแวดล้อม Python ใบรับรอง และไฟล์ทดลองจะถูกซ่อนใน Explorer ตาม `.vscode/settings.json` หากต้องการดู ให้ปรับ `files.exclude` ในไฟล์นี้

การจัดหมวดไม่ลบผลทดสอบ ภาพตัวอย่าง หรือสำรองข้อมูล และไม่ย้ายฐานข้อมูลจริง วิดีโอจริง ใบรับรอง หรือไฟล์ที่ตัวเปิดระบบยังใช้งานอยู่
